# ЗОНК — Золото Южных Морей

Telegram Mini App для счёта в игре в кости **ЗОНК**. Не игра, а судовой журнал:
считает, спорит и помнит. Пиратская Бухта — орки, мурлоки, гоблины и тролли режутся
в кости на золото под масляными фонарями. Кто первым соберёт **Главный Сундук**
(1000 золота), забирает банк.

Тёмный трюм, мокрое от соли дерево, красные тряпки и холодные искры магического
планктона. 100% pixel art, всё нарисовано кодом.

React 19 · Vite 6 · Zustand 5 · Tailwind CSS 4 · Telegram WebApp API · vite-plugin-pwa


## Выкатка в Telegram

Mini App живёт по HTTPS-адресу, который знает бот. Порядок такой:

**1. Собрать и выложить.**

```bash
npm run build
```

Папку `dist/` — на любой статический хостинг: GitHub Pages, Netlify, Vercel,
Cloudflare Pages. `base: './'` уже настроен, работает и из подпапки.
Для быстрой пробы годится временный туннель:

```bash
npx cloudflared tunnel --url http://localhost:4173
```

**2. Привязать к боту.** В [@BotFather](https://t.me/BotFather):

```
/newapp  → выбрать бота → название, описание, иконка 640×360 → HTTPS-адрес
```

Либо кнопкой в меню: `/mybots` → бот → **Bot Settings → Menu Button** → URL.

**Быстрее — одной командой.** Токен передаётся переменной окружения и в файлы
не попадает:

```bash
export BOT_TOKEN=123:ABC          # в PowerShell: $env:BOT_TOKEN = "123:ABC"
npm run tg -- https://твой-адрес  # кнопка меню, описания, /start
npm run tg -- --check             # посмотреть, что настроено, ничего не меняя
```

Скрипт [`tools/tg-setup.mjs`](tools/tg-setup.mjs) ставит кнопку меню типа
`web_app`, краткое и полное описание бота и команду `/start`. Прямую ссылку вида
`t.me/бот/приложение` через Bot API не создать — она делается только через
`/newapp` в @BotFather.

**3. Открыть в Telegram** и убедиться, что шапка тёмная, свайп вниз не закрывает
приложение, а победа записывается в славу.

> **Токен бота в приложение не кладётся никогда.** Mini App целиком выполняется
> в браузере: всё, что в него попало, видно любому. Токен нужен только серверу.
> Если токен где-то засветился — отзови его в @BotFather (`API Token → Revoke`).

### Что даёт Telegram

Всё в [`src/tma/telegram.js`](src/tma/telegram.js) — тонкая обёртка, вне мессенджера
не делает ничего, и приложение одинаково работает как обычная PWA:

| Возможность | Зачем |
|---|---|
| `ready()` + `expand()` | развернуть на весь экран сразу |
| `disableVerticalSwipes()` | свайп вниз закрывал бы игру при листании свитков |
| `setHeaderColor` / `setBackgroundColor` / `setBottomBarColor` | хром клиента красится под трюм |
| `safeAreaInset` + `contentSafeAreaInset` | отступы уезжают в CSS-переменные `--tg-top` / `--tg-bottom` |
| `HapticFeedback` | отклик в руку на каждое нажатие, победу и штраф |
| `BackButton` | из Кодекса — на причал, из партии — на берег |
| `CloudStorage` | слава Бухты переезжает между устройствами |

Каждый вызов защищён от старых клиентов и от версии, где метода ещё нет.
Вне Telegram обёртка не трогает API вовсе — консоль остаётся чистой,
а слава ложится в `localStorage`.

```
  audio/synth.js          ← процедурные звуки на WebAudio (файлы не нужны)
  audio/sfx.js            ← чип-звуки sfxr, сгенерированы и зафиксированы
  audio/audioManager.js   ← событие движка → звук + голос + тряска экрана
  audio/bus.js            ← шина событий между стором и интерфейсом

  data/races.js           ← орк, мурлок, гоблин, тролль

tools/
  gen-assets.mjs          ← рисует все PNG процедурно: текстуры, спрайты, очаг
  gen-sfx.mjs             ← генерирует чип-звуки sfxr с фиксированным зерном
  fetch-fonts.mjs         ← тянет пиксельные шрифты с кириллицей в public/fonts
  shots.mjs               ← сценарий в мобильном браузере + поддельный Telegram
  check-board.mjs         ← стол на четверых: подсветка хода и автопрокрутка
  check-finale.mjs        ← последний круг, общая победа, пометка первого
  tg-setup.mjs            ← настройка бота через Bot API
  build-single.mjs        ← склейка всего в один zonk.html
  check-build.mjs         ← приёмка прод-сборки: манифест, шрифты, SW, офлайн
```

**Правила отделены от всего остального.** `rulesEngine.js` принимает снимок игры и
действие, возвращает новых игроков, новые записи и список событий. Он не знает ни
про React, ни про стор, ни про Telegram — поэтому его целиком покрывают тесты,
а спорные правила Бухты можно менять, не трогая интерфейс.

## Путь игрока

**Причал** → «Кодекс Бухты» (команда и правила) → «Снять якорь» → **Стол** → «Сундук наш».

С причала открываются ещё два экрана: **«Правила»** — справочник комбинаций
с отрисованными костями, и **«Слава Бухты»** — победы по именам.

Якорь не снять, пока не заглянул в Кодекс: там собирают команду. Победы копятся
в «Славе Бухты» по имени персонажа и переживают перезапуск.

## Правила и настройки

Всё настраивается в Кодексе — до партии и во время неё (☰ в верхней балке).
В скобках — значение по обычаю.

| Правило | Что делает |
|---|---|
| **Главный Сундук** (1000, ровно) | Сколько золота собрать. Точный финиш — перебор сгорает |
| **Башлять в общак** (50) | Минимум за ход, чтобы впервые вписаться в свиток |
| **Бочка с пойлом** (880 · 3 глотка · −120) | Ловит всех, кто дошёл **или перевалил**: садишься ровно на её число, лишнее пропадает |
| **Спихнуть с бочки** (вкл.) | Соперник, вставший на ту же бочку, сбрасывает сидящего. **Вдвоём — не может** |
| **Дырявая лодка** (555 → 0) | Попал ровно на число — весь груз на дно |
| **Уловы** (125 / 250) | Малый и большой стриты на трёх костях |
| **Гарпун в спину** (−50) | **Встал на то же число, что и соперник** — соперник платит. Обгон безнаказан |
| **Ржавые крючки** (3 → −100) | Пустые броски. Три подряд — рваная сеть и списание |
| **Суд Хозяина Бухты** | «Кость за борт» и «Кривой штурвал» — ровно один крючок, золото не трогают |
| **Шаг счёта** (5) | Всё кратно пяти. Ввести кривое число нечем — в пульте только номиналы |
| **Дно счёта** (0) | Счёт никогда не уходит в минус. Любое списание останавливается на нуле — настройки у этого правила нет |

### Бочка: как с неё сходят

Правило отдельное, потому что чаще всего именно в нём путаются:

- На бочке золото **не пишется** — тратятся глотки.
- Чтобы забрать сундук, за один ход нужно набрать **не меньше 120** (880 + 120 = 1000).
- Всё сверх 120 **за борт**: счёт фиксируется ровно на 1000.
- Набрал меньше 120 — кнопка записи заблокирована. Это провал: жмёшь
  «Ржавый крючок», глоток сгорает.
- Глотки кончились — падаешь с бочки на −120.
- **На бочке крючки не идут в рваную сеть.** Счёт ведут только глотки,
  расплата одна — падение по настройке бочки. Двух наказаний за один
  промах не бывает.

### Финал: последний круг

Взятый сундук партию **не обрывает**:

- Тот, кто первым собрал 1000, объявляется победителем и помечается «ПЕРВЫЙ».
- У всех остальных есть **ровно по одному последнему ходу**, чтобы догнать.
- Кто успел добрать до 1000 — тоже победитель, помечается «УСПЕЛ».
- Партия заканчивается, когда последний круг доигран. Слава засчитывает
  победу всем, кто успел.

Остальные тонкости:

- **Бочку нельзя перепрыгнуть.** Было 780, выбросил 150 — не 930, а 880 и на бочку.
  Если за ход перекрыто несколько бочек, ловит самая нижняя.
- Равенство считается по счёту соперника **на начало хода**. Сидящего на бочке
  гарпун не трогает: за бочку отвечает сброс, а он вдвоём запрещён.
- Удачный ход гасит накопленные крючки.
- Игрока на нуле в спину не бьют.
- **Долгов в Бухте не пишут.** Рваная сеть, гарпун и падение с бочки
  упираются в ноль и ниже не идут.

## Свиток

Счёт пишется в столбик, как в судовом журнале: в строке — нарастающий итог, мелко
рядом — прибавка за ход.

- **Ржавый крючок** — пиксельный крючок поперёк колонки вместо прочерка.
- **Три крючка** — перечёркиваются красной сетью, ниже пишется списание,
  отсчёт начинается заново.
- **Бочка** — число обводится обручами с золотым кольцом. И в строке, и в шапке
  свитка, пока игрок на ней сидит.
- **Штрафы** — красным, с коротким словом: РВАНАЯ СЕТЬ, ГАРПУН, СПИХНУТ, УПАЛ, ПРОБОИНА.
- **Сгоревшие попытки** — бледный ✕ с подписью (глоток, перебор, не башлял).

Свитков больше трёх — стол листается вбок, край следующего виден.
Нажатие на шапку свитка открывает **правку писаря**: ручная корректировка счёта,
если за столом вышел спор. Кнопка ↶ откатывает последнюю запись (до 30 шагов).

## Звук

Работает из коробки, без единого звукового файла: стук костей, удар кружки,
скрип пера, грохот бочки и рог победы синтезируются на WebAudio.
Автоплей обойдён честно — `AudioContext` создаётся в обработчике первого касания.

Голоса (в том числе басистый орк-пират из TTS) подключаются паками: слоты
размечены, файлов в поставке нет. Подробности:
[`public/sounds/README.md`](public/sounds/README.md).

Сильные события дополнительно трясут экран и дают вибрацию — в Telegram родную,
в браузере через Vibration API.

## Ассеты

Ни одной картинки не скачано со стороны — всё рисуется кодом:

```bash
npm run assets   # карта, палуба, трюм с планктоном, лента, крючок, златой, сундук
```

`tools/gen-assets.mjs` содержит собственный PNG-энкодер на `node:zlib` и генератор
бесшовного шума. Морская карта — многооктавный шум, квантованный в пять ступеней
(потому и выглядит пиксель-артом, а не градиентом), плюс разводы солёной воды.

Шрифты — пиксельные, **с кириллицей**. Из готических пиксель-шрифтов Google Fonts
кириллицу имеют пять, и у большинства цифра «5» неотличима от «S» (Pixelify Sans
забракован именно поэтому). Остались **Handjet** в тяжёлых начертаниях 800–900 —
цифры читаются однозначно — и **Tiny5** на мелкие подписи. Лежат локально, 61 КБ:

```bash
npm run fonts    # перекачать из Google Fonts
```

## Проверка

```bash
npm test                   # 40 тестов правил
npm run dev                # в одном окне
npm run shots -- ./shots   # в другом
npm run check-board        # стол на четверых: рамка и автопрокрутка
npm run check-finale       # последний круг и общая победа
```

Сценарий прогоняет партию в headless Chrome/Edge при 390×844 и 360×640 и
подсовывает **поддельный `window.Telegram.WebApp`** — так проверяется ветка Mini App
целиком: свайпы, цвета хрома, haptics, кнопка «назад», облачное хранилище и
безопасные отступы. Заодно проверяются игровые инварианты: бочка ловит
перевалившего, недобор на бочке блокирует запись, крючок при этом остаётся на
экране, при 120+ кнопка меняется на «Забрать сундук», лишнее уходит за борт.

```bash
npm run build && npm run preview
npm run check-build        # манифест, шрифты, service worker, офлайн
```

### Один файл без сервера

```bash
npm run single       # zonk.html — всё внутри как data:-строки
npm run check-single # приёмка по file://
```

Пригодится, чтобы играть без Telegram и без сети: перекинул файл на телефон и открыл.
