# Звуки Пиратской Бухты

## Как это устроено

Звук идёт двумя слоями.

**1. Звуки** — стук костей, глухой удар кружки о стол, скрип пера, грохот
перевёрнутой бочки, рог победы. Они **уже работают**: генерируются процедурно на
WebAudio (`src/audio/synth.js`), файлов не требуют и весят ноль байт.

Хочешь заменить любой звук своим — положи сюда файл с нужным именем, и приложение
подхватит его вместо синтеза. Ничего в коде править не надо.

| Файл | Когда играет |
|---|---|
| `sword.mp3` | штраф, гарпун в спину, сброс с бочки, рваная сеть |
| `mug.mp3` | крупный улов, начало партии |
| `quill.mp3` | обычная запись в свиток |
| `dice.mp3` | перестук костей |
| `bolt.mp3` | ржавый крючок, сгоревший глоток, перебор |
| `barrel.mp3` | игрок влез на бочку |
| `crash.mp3` | дырявая лодка, падение с бочки |
| `horn.mp3` | сундук забран |
| `click.mp3` | нажатие кнопки |
| `scrape.mp3` | откат записи |

Формат: `.mp3`, моно или стерео, короткие (до 1.5 с), нормализованные.

## 2. Голоса

Реплики поверх звуков. Пак выбирается в **Кодекс → Правила → Прочее → Голоса**.

**Файлов в поставке нет намеренно.** Архитектура под них готова: положи свои файлы
в папку пака — они зазвучат. Нет файла — приложение молча играет только
процедурный звук, без единой ошибки в консоли.

### Пак «Орк-пират» → `voice/pirate/`

Рассчитан на синтезированный басистый голос. Возьми реплики из `src/data/lore.js`
(объект `REACTIONS`), прогони через любой TTS с низким мужским голосом — и разложи
по именам:

| Файл | Событие | Что говорить |
|---|---|---|
| `anchor.mp3` | начало партии | «Якорь поднят! Кости на стол.» |
| `coin1.mp3`, `coin2.mp3` | обычная запись | «Звенит монета! Записано.» |
| `big1.mp3`, `big2.mp3` | улов от 300 | «ВО-О-ОТ ЭТО УЛОВ!» |
| `miss1.mp3`, `miss2.mp3` | ржавый крючок | «Пусто. Мурлоки смеются над тобой.» |
| `net.mp3` | рваная сеть | «Сеть порвана! Золото уходит на дно!» |
| `barrel.mp3` | влез на бочку | «Влез на бочку! Отсюда только к сундуку.» |
| `sip.mp3` | сгоревший глоток | «Мимо. Один глоток сгорел.» |
| `fall.mp3` | упал с бочки | «Упал под стол! Мордой в опилки.» |
| `harpoon.mp3` | гарпун в спину | «Нож под ребро! Отдавай золото!» |
| `leak.mp3` | дырявая лодка | «Дно пробито! Вычерпывай воду, черви!» |
| `spill.mp3` | перебор | «Через край не наливают.» |
| `foul.mp3` | суд Хозяина Бухты | «Кто так кидает?!» |
| `chest1.mp3`, `chest2.mp3` | победа | «СУНДУК НАШ! Гроза Южных Морей!» |

Несколько файлов на слот — выбирается случайный, реплики не приедаются.

### Пак «Команда» → `voice/crew/`

Хор за столом: `cheer.mp3` (запись), `boo.mp3` (крючок), `cheer_big.mp3` (победа).

### Свой пак

Добавляется одной записью в `src/data/lore.js` → `VOICE_PACKS`:

```js
myPack: {
  label: 'Мои голоса',
  dir: '/sounds/voice/mypack/',
  lines: {
    bolt: ['oops.mp3', 'nope.mp3'],   // можно несколько — выберется случайная
    win: ['yes.mp3'],
  },
},
```

Слоты событий: `gameStart`, `score`, `bigScore`, `bolt`, `boltPenalty`, `barrelSit`,
`barrelMiss`, `barrelFall`, `knockOff`, `wagon`, `backstab`, `overshoot`, `noEntry`,
`foul`, `win`.

## Автоплей

Браузеры и Telegram не дают звуку играть до первого касания. Приложение это
учитывает: `AudioContext` создаётся в обработчике самого первого тапа
(см. `tap()` в `src/components/ui.jsx` и пробуждение в `App.jsx`), поэтому первый
же нажатый номинал уже звучит. Голоса не тараторят: между репликами выдерживается
пауза в 1.2 секунды.
